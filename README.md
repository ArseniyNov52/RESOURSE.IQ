Resource Intelligence Platform

Веб-приложение для управления загрузкой сотрудников

О проекте

Resource Intelligence Platform — это дизайн-концепция веб-приложения для управления загрузкой сотрудников в IT-компаниях.

Проект включает 6 полноценных экранов десктопной версии (1440px) и мобильные версии (375×812).
Все тексты — на русском языке.

Интерфейс выполнен в современном B2B SaaS стиле и оптимизирован для дальнейшей разработки.

Цель проекта

Создать набор редактируемых UI-фреймов, которые:

отображают загрузку сотрудников

показывают риски проектов

позволяют перераспределять задачи

поддерживают симуляцию сценариев

показывают стратегические приоритеты

предоставляют аналитику и KPI

Все компоненты должны быть подготовлены для дальнейшей интеграции в реальный продукт.
