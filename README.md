# 🚀 Resource Intelligence Platform

**Resource Intelligence Platform** — веб-приложение для управления загрузкой сотрудников, анализа рисков проектов и интеллектуального перераспределения ресурсов.

Платформа помогает:
- 📊 Отслеживать загрузку команды в реальном времени  
- 🔥 Предотвращать перегруз и выгорание  
- ⚠️ Снижать риски срыва дедлайнов  
- 🎯 Приоритизировать проекты по бизнес-ценности  
- 🎮 Моделировать сценарии (What-if анализ)  

---

# 🖥 Дизайн-система

## 🌐 Общие настройки
- **Стиль:** современный B2B SaaS (в духе Linear / Asana)  
- **Тема:** светлая  
- **Фон:** белый  
- **Скругления:** 8px  
- **Сетка:** 8px spacing (Auto Layout)  
- **Шрифт:** Inter (с поддержкой кириллицы)  
- **Основной цвет:** `#4F46E5`  
- **Success:** зелёный  
- **Warning:** жёлтый  
- **Overload:** красный  

### Верхняя навигация
- Логотип (слева)  
- Меню:  
  - Обзор  
  - Команда  
  - Проекты  
  - Симулятор  
  - Аналитика  
- Аватар пользователя (справа)  

---

# 📱 Поддержка адаптивности
Подготовлены версии:
- **Desktop:** 1440px  
- **Mobile:** 375×812  

Все компоненты:
- Используют **Auto Layout**  
- Имеют корректные **Constraints**  
- Поддерживают **wrap текста**  
- Используют **truncation с "…"**  
- Не имеют наложений элементов
